# Motfilm Pro 4K - Production OTT Streaming Platform

Ứng dụng xem phim trực tuyến thế hệ mới, tối ưu hóa phát luồng HLS v7 Adaptive Streaming, lưu lịch sử xem dở và giao diện chuẩn điện ảnh.

## 🚀 Triển Khai Miễn Phí Lên Vercel (Trong 60 Giây)

1. Tải về hoặc giải nén thư mục mã nguồn này.
2. Truy cập [vercel.com](https://vercel.com) và đăng nhập bằng GitHub hoặc Email.
3. Bấm **Add New...** > **Project**, kéo thả thư mục dự án hoặc chọn GitHub Repo của bạn.
4. Chọn cấu hình mặc định:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Bấm **Deploy**. Sau 1 phút bạn sẽ có ngay tên miền riêng (ví dụ: `https://motfilm-pro.vercel.app`), mở được trên mọi thiết bị và không phụ thuộc vào tài khoản Google!

```bash

npm install

http://localhost:3000
```
